# cl-st1_ph1_anna - Pipeline Programmes

This document summarises the programmes used in the Phase 1 pilot Lexical Multi-dimensional Analysis pipeline for the Phase 1 project. The pipeline processes the cleaned paragraph-level EF Sudeste pilot curriculum corpus, extracts and selects state-based keywords, builds SAS input files, runs the external SAS LMDA workflow, and generates post-SAS reporting materials such as factor lists, corpus-size summaries, plots, ANOVA tables, and representative examples.

### Key lemmas extration by `keylemmas.py`

In simple terms, **`keylemmas.py` finds the lemmas that distinguish each state’s curriculum paragraphs from the other states’ paragraphs** using log-likelihood to determine whether the differences are statistically significant.

For example, it can help identify lexical items that are unusually common in the Espírito Santo curriculum texts compared with Minas Gerais, Rio de Janeiro, and São Paulo, and so on for each state.

These candidate key lemmas then feed into the keyword-selection step, which produces the final list of lexical variables used in the SAS-based Lexical Multi-dimensional Analysis.

## Pipeline Overview

The pipeline can be understood as four broad stages:

| Stage                       | Description                                                                                                                    | Programmes                                                                                                                             |
|-----------------------------|--------------------------------------------------------------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------------|
| Corpus preparation          | Tag the cleaned paragraph-level EF Sudeste pilot corpus and identify key lexical items by state.                               | `tag.py`, `keylemmas.py`                                                                                                               |
| Keyword matrix construction | Select state-stratified keywords, build keyword columns, and merge them into the SAS counts matrix.                            | `select_kws_stratified.py`, `columns.py`, `merge_columns.py`, `sas_formats.py`                                                         |
| SAS-based LMDA              | Run the external SAS Lexical Multi-dimensional Analysis workflow to generate factor scores, loadings, ANOVA results, and other statistical outputs. | SAS workflow                                                                                                                           |
| Post-SAS reporting          | Convert SAS outputs into readable factor lists, corpus summaries, plots, tables, selected examples, and score-detail reports.  | `factor_lists.py`, `corpus_size.py`, `latex_boxplots.py`, `latex_anova_table.py`, `examples.py`, `score_details.py`, `examples_txt.py` |

## Notes

- The pipeline should be run from the Phase 1 project directory.
- The corpus is organised by state: `es`, `mg`, `rj`, and `sp`.
- The analysis uses cleaned paragraph-level curriculum texts from the EF Sudeste pilot corpus.
- Very short paragraphs, when removed during preprocessing, should remain excluded from both the extracted and tagged corpus directories before rerunning the LMDA pipeline.
- The SAS step is external and must be completed before the post-SAS programmes can produce factor lists, ANOVA tables, boxplots, representative examples, and score-detail reports.
